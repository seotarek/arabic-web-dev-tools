معظم المكتبات المتاحة تتطلب تثبيت حزم ضخمة تستنزف حزمة البناء. تم تصميم هذه المكتبة لتعمل بمفردها بنسبة 100% كـ ES Modules أصلية دون أي حزمة خارجية.

الانتقال إلى CSS Logical Properties

استبدال النمط القديم لعكس ملفات الـ CSS بقواعد W3C الحديثة (مثل margin-inline-start) مما يتيح للموقع العمل بكود واحد يدعم العربية والإنجليزية في آن واحد.

محاذاة الترقيم وعزل الـ BiDi

معالجة الخلل الشهير حيث تقفز النقطة أو علامة التعجب إلى أول السطر عندما ينتهي السطر العربي برابط أو كلمة إنجليزية، باستخدام علامات RLM والـ Directional Isolates.
